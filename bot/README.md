# בוט התקציב

בוט טלגרם שקורא את הפיד של RiseUp כל חצי שעה, ומודיע לכם על כל **הוצאה משתנה**
חדשה — כמה היא, לאיזו קטגוריה, כמה נשאר בה וכמה ימים נותרו לחודש.

```
🧾 עסקה חדשה
מיקה מודיעין · 466 ₪
קטגוריה: רכב

עד כה החודש: 1,841 מתוך 2,000 ₪
נותרו 159 ₪ · 17 ימים לסוף החודש
⚠️ מקדימים את הקצב — לפי התאריך היו אמורים להיות ב-933 ₪

💬 עוד לא קרה כלום. אבל מתחיל לקרות משהו.
— מוסלם
```

## האופי

מוסלם מגיב לפי חומרת המצב, בארבעה רגיסטרים:

| מצב | דוגמה |
|---|---|
| בתוך הקצב | „בסדר גמור. אני רושם, אבל בסדר גמור.” |
| מקדימים ב-15%+ | „הלו הלו נשמות, בואו נרגיע לפני שאני משתגע.” |
| חריגה | „נגמר. הקטגוריה הזאת נגמרה. סגרנו.” |
| חריגה של 50%+ | „אתם צוחקים עליי? תגידו לי שאתם צוחקים עליי.” |

**81 משפטים** בסך הכול — 62 תגובות לעסקאות ו-19 פתיחים לסיכום הערב.
המשפט נבחר לפי מזהה העסקה, כך שאותה עסקה תמיד תיתן את אותו משפט אבל בין
עסקאות יש גיוון. הכול ב-`budgetbot/persona.py`.

**`PERSONA=0`** ב-`.env` מחזיר הודעות יבשות. המספרים זהים בשתי הגרסאות.

בערב מגיע גם סיכום יומי של כל הקטגוריות, ואפשר לשאול בכל רגע עם `/status`.

## התקנה על הרספברי

דרוש Docker ו-Docker Compose. שבעה צעדים, פעם אחת.

**1. יוצרים את הבוט.** בטלגרם, ל-`@BotFather`: `/newbot` → שם → יוזרניים.
מקבלים טוקן שנראה כמו `123456789:AAH…`.

**2. פותחים קבוצה** עם עדן, מוסיפים אליה את הבוט, ושולחים בה הודעה כלשהי.
*(בוט לא יכול לכתוב למי שלא פתח איתו שיחה — לכן קבוצה נוחה יותר משתי שיחות.)*

**3. מחליפים את ה-PAT של RiseUp.** הישן נחשף בשיחה שבה נבנה הבוט.

**4. ממלאים את הסודות:**
```bash
git clone <repo> && cd calories/bot
cp .env.example .env && chmod 600 .env
nano .env          # RISEUP_PAT ו-TELEGRAM_BOT_TOKEN
```

**5. מגלים את ה-chat id:**
```bash
docker compose run --rm bot whoami
```
מעתיקים את השורה `TELEGRAM_CHAT_IDS=…` שהוא מדפיס לתוך `.env`.

**6. בודקים:**
```bash
docker compose run --rm bot selftest --telegram
```
אמורה להגיע הודעת בדיקה לקבוצה.

**7. מרימים:**
```bash
docker compose up -d
docker compose logs -f
```

בהרצה הראשונה הבוט **לא** מציף אתכם בהתראות על כל החודש שכבר עבר — הוא קולט
את המצב בשקט ושולח הודעת מצב אחת.

## הפעלה מהשורה

```bash
docker compose run --rm bot status          # מצב, בלי לשלוח כלום
docker compose run --rm bot poll --dry-run  # מחזור אחד, מדפיס במקום לשלוח
docker compose run --rm bot poll --force    # מתעלם משעות שקט
docker compose logs -f                      # לוגים
docker compose restart                      # אחרי שינוי ב-.env
```

## איך זה מחליט מה נכנס לתקציב

- **מוחרגים:** הכנסות, עסקאות ש-RiseUp מסמנת כמוחרגות, חיובי כרטיס מרוכזים
  בעו״ש (אחרת כל קנייה בכרטיס נספרת פעמיים), והפקדות לחיסכון.
- **עסקאות עתידיות לא נספרות.** בפיד יש הוראות קבע מתוזמנות ימים מראש —
  ספירה שלהן הייתה מדווחת על כסף שעוד לא יצא.
- **קבוע מול משתנה:** לפי `actualType` של RiseUp, בתוספת רשימת בתי עסק
  שהוגדרו ידנית כקבועים (תפארת האחוזה, צהרון, יח״ד ועוד) ב-`config.py`.
  הבוט **לא** שולח התראות על הוצאות קבועות — רק סופר אותן לסיכום.
- **הסכומים מחושבים מחדש מהמסד בכל מחזור**, ולא נצברים במונה. כך עסקה שמגיעה
  באיחור של יומיים מתקנת את המספר במקום לעוות אותו. גם שינוי סכום (עסקה
  שנסגרה אחרת ממה שנרשמה) מזוהה ומדווח.

## פיתוח

```bash
cd bot
python3 -m unittest discover -s tests -t .
RISEUP_PAT=… DB_PATH=/tmp/t.db python3 -m budgetbot poll --dry-run
```

ללא תלויות חיצוניות — Python 3.11+ ו-stdlib בלבד.

## אבטחה

`.env` לא נכנס ל-git (יש `.gitignore`), לא נכנס לאימג' (נטען ב-`env_file`),
והטוקנים ממוסכים מהודעות שגיאה ומהלוגים. הקונטיינר רץ כמשתמש לא-root.
